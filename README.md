# Adventure App

Gamified adventure map app.

## Feature 1 — Real Map

Interactive OpenStreetMap via Leaflet (`react-leaflet`), centered on Riyadh / Saudi Arabia.

**Branch:** `feature/real-map` (not merged to `main` yet)

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS
- Leaflet + react-leaflet + OpenStreetMap tiles

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Pan and zoom the map; a marker marks Riyadh.

```bash
npm run build   # production build
npm start       # serve production build
```
